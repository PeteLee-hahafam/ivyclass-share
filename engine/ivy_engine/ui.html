이 화면은 닫아도 돼요. 검은 엔진 창을 닫으면 엔진이 멈춰요.

1

강의실 연결

사이트에서 받은 설치 파일로 설치했다면 이미 연결돼 있어요. 따로 넣을 때는 강의실 사이트 → 설정 → 제작 엔진의 연결 코드를 붙여 넣으세요.

2

대본 쓰기 (Claude)

Claude Console(console.anthropic.com) → API Keys에서 만든 키를 넣으세요. 키는 이 PC에만 저장되고 강의실 사이트로는 보내지 않아요.

3

선생님 목소리

들어 보고 고르세요. 가장 사람 같은 건 ElevenLabs예요. 내 목소리를 복제해서 쓸 수도 있어요.

키가 필요 없어요. 인터넷만 있으면 돼요.
Google Cloud 콘솔에서 Text-to-Speech API를 켜고 키를 만들어 넣으세요. 매달 100만 글자(강의 200개쯤)까지 무료예요.
Google AI Studio(aistudio.google.com)에서 키를 만들어요. 15분 강의에 약 300원이에요.
한국어가 자연스러우려면 한국어 목소리를 고르세요. 기본 목소리는 영어 원어민이라 한국어가 조금 어색할 수 있어요. ElevenLabs 사이트의 Voice Library에서 언어를 Korean으로 골라 마음에 드는 목소리를 내 목소리에 담거나(Add to my voices), 내 목소리를 복제(Voices → Add voice)한 뒤 내 계정 목소리 불러오기를 누르세요. 한국어 목소리가 맨 위에 나와요.
키는 elevenlabs.io → Developers → API Keys에서 만들어요. 요금은 Starter 월 6달러(15분 강의 6개쯤), Creator 월 22달러(24개쯤)예요. 학원에서 쓰려면 Starter 이상이 필요해요.
키는 Typecast API 콘솔(studio.typecast.ai/developers/api)에서 만들어요. 키를 넣고 목소리 불러오기를 누르면 내가 만든 목소리와 교육용 목소리가 맨 위에 나와요. 들어 보기로 영어 문장 발음까지 비교해 보세요.
요금은 무료 1만 5천 자(15분 강의 3개쯤, 상업 이용 불가), Lite 월 15달러에 20만 자(15분 강의 40개쯤)예요.
강의 중 학생 이름을 부르는 자리에서, 선생님이 미리 보거나 이름 목소리가 아직 없을 때 대신 하는 말이에요.
4

자동 자막 (내가 찍은 강의)

선생님이 올린 강의 영상의 말을 이 PC가 받아 적어요. 돈이 들지 않아요.

처음 한 번은 모델을 내려받느라 시간이 걸려요. 15분 강의는 보통 5~10분이면 받아 적어요.
