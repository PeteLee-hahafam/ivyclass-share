# 온라인 강의실 (학원용, 무료)

영어 지문을 넣으면 **선생님이 판서하며 설명하는 강의 영상**을 만들어 주고, 학생은 휴대폰으로 보고, 선생님은 **누가 어디까지 봤는지** 한눈에 보는 학원용 프로그램이에요. 학원에서 영어를 가르치는 선생님이 직접 만들어 쓰는 것을 무료로 나눠요.

- 지문을 넣으면 AI 대본, 사람 같은 목소리, 펜이 직접 그리는 판서 영상, 판서노트와 연습지 PDF까지 만들어요
- 강의 중에 보는 학생의 이름을 불러 줘요
- 선생님이 찍은 영상도 올려서 자르기, 목차, 자동 자막, AI 요약을 붙일 수 있어요
- 학생 앱은 실제로 본 곳만 시청으로 쳐요. 건너뛰기 막기, 과제 마감, 안 본 학생 알림 문구 복사
- 학생 정보는 각 학원의 Cloudflare 계정에만 저장돼요. 만든 사람은 볼 수 없어요.

## 준비물

| 무엇 | 비용 |
|---|---|
| 윈도우 PC 1대 (학원 PC, 강의 영상을 만들어요) | 쓰던 PC면 돼요 |
| [Cloudflare](https://dash.cloudflare.com) 계정 | 무료. 영상 보관함을 켤 때 카드를 등록하지만 10GB까지는 무료예요 |
| [GitHub](https://github.com) 계정 | 무료 |
| [Claude API 키](https://console.anthropic.com) | 미리 충전해서 써요. 15분 강의 1개에 약 200원 |
| 목소리 | 무료 목소리로 시작해요. 더 사람 같은 목소리는 엔진 설정에서 유료로 고를 수 있어요 |

## 설치 (30분쯤)

1. **가입**: GitHub와 Cloudflare에 가입해요.
2. **영상 보관함 켜기**: Cloudflare 왼쪽 메뉴 **R2 Object Storage** → 처음이면 구독(무료) → 카드 등록.
3. **강의실 만들기**: 아래 버튼을 눌러요.

   [![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/PeteLee-hahafam/ivyclass-share)

   - GitHub 연결을 물으면 허용해요. 내 GitHub에 강의실 저장소가 하나 생겨요.
   - 데이터베이스(DB)와 영상 보관함(BUCKET)은 새로 만들어요. 이름은 그대로 두면 돼요.
   - **SETUP_CODE** 칸에는 8자 이상 비밀 코드를 정해 넣고 **꼭 적어 두세요.** 처음 설정과 비상 계정 되찾기에 써요.
   - 마지막에 만들기(Create and deploy) 버튼을 눌러요.
4. **처음 설정**: 1~2분 뒤 생긴 주소(`https://ivyclass.<내 이름>.workers.dev`)를 열어요. SETUP_CODE, 학원 이름, 선생님 아이디와 비밀번호를 넣어요. 마지막에 나오는 **복구 코드**는 휴대폰으로 사진을 찍어 두세요.
5. **제작 엔진 설치**: 학원 PC에서 강의실에 로그인 → **설정 → 제작 엔진 → 엔진 설치 파일 받기** → 받은 파일 실행. 파란 경고 창이 뜨면 **추가 정보 → 실행**을 눌러요. 엔진 설정 화면이 열리면 Claude API 키를 넣어요.
6. **반과 학생**: **반 → 반 만들기 → 학생 넣기**. 학생에게 주소와 아이디, 비밀번호를 알려 주면 휴대폰에서 '홈 화면에 추가'해서 앱처럼 써요.

## 업데이트

- **저절로 돼요.** 내 GitHub의 강의실 저장소가 6시간마다 새 버전을 받아 오고, 그러면 Cloudflare가 사이트를, 사이트가 학원 PC 엔진을 새 버전으로 바꿔요.
- 강의, 학생 기록, 학원 설정은 그대로예요.
- 바로 받으려면: 내 GitHub 강의실 저장소 → **Actions** → **강의실 업데이트** → **Run workflow**
- Actions에 '강의실 업데이트'가 꺼져 있다고 나오면 **Enable workflow**를 눌러 켜 주세요.
- 코드를 직접 고쳐 쓰려면 이 작업을 꺼 주세요. 켜 두면 고친 곳이 새 버전으로 덮어써져요.

## 비밀번호를 잊었을 때

- **학생**: 선생님이 반 → 학생 목록의 열쇠 단추로 새 비밀번호를 만들어 줘요.
- **선생님**: 로그인 화면 → **아이디나 비밀번호를 잊었어요** → 복구 코드를 넣어요. 복구 코드가 없으면 **복구 코드도 잃어버렸어요** → SETUP_CODE를 넣어요.
- SETUP_CODE까지 잊었으면 Cloudflare → Workers & Pages → 내 강의실 → Settings → Variables and Secrets에서 SETUP_CODE를 새 값으로 바꾸고 그 값을 넣어요.
